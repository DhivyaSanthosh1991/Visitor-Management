╔══════════════════════════════════════════════════════════════╗
║                  INSTALLATION STEPS                          ║
╚══════════════════════════════════════════════════════════════╝

STEP 1: Create the folder structure
------------------------------------
1. Create folder: C:\startuptn-visitor-system
2. Inside it, create subfolder: src

STEP 2: Place downloaded files
-------------------------------
1. Put package.json, vite.config.js, index.html in ROOT folder
2. Put main.jsx, index.css, visitor-management.jsx in SRC folder

STEP 3: Install dependencies
-----------------------------
Open Command Prompt in C:\startuptn-visitor-system

Run:
cd C:\startuptn-visitor-system
npm install

(This will take 1-2 minutes)

STEP 4: Run the application
----------------------------
npm run dev

STEP 5: Open in browser
------------------------
Terminal will show something like:
  ➜  Local:   http://localhost:5173/

Copy that EXACT URL and paste in your browser

╔══════════════════════════════════════════════════════════════╗
║                  TROUBLESHOOTING                             ║
╚══════════════════════════════════════════════════════════════╝

Problem: "Cannot find module"
Solution: Make sure you ran "npm install"

Problem: "Failed to load /src/main.jsx"
Solution: Check that main.jsx is inside the src/ folder

Problem: Port already in use
Solution: Close other terminals and run "npm run dev" again

Problem: Localhost 404
Solution: Make sure npm run dev is running and use the exact URL shown
